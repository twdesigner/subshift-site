WebVTT specification

Built for modern web video players

WebVTT is the default subtitle standard for HTML5 video elements. SubShift formats track indicators, time dividers, cues, and styles to match the spec exactly.

  • Compliant with standard HTML5 video track players
  • Works with video.js, JW Player, and Plyr
  • Supports custom line coordinates, cue positioning, and alignment
  • Keeps subtitle colors, bold weight, and italic tags intact

FAQ

Frequently asked questions

Are my subtitle files securely processed?

Yes, 100%. SubShift compiles files locally in your browser. Your subtitle text and timestamps are never uploaded to any server or cloud database.

What is the difference between SRT and VTT?

SRT is a plain-text subtitle format built for desktop media players. WebVTT (VTT) is designed for modern HTML5 browser players and supports styles, positioning, and cues.

Can I convert massive movie or track lengths?

Yes. Because conversion runs locally in memory, you can process files of any length without hitting typical upload or API size limits.
